# 原著 IP 元素使用指南

## 使用原则

可以使用原著人物、地点、阵营、课程、魔法物件和已知世界规则来增强同人识别度，但不要复制原著长段文字，不要复刻原著章节，不要把原著台词大段搬入正文。目标是“可识别的同人世界 + 原创中文情节表达”。

## 高识别度地点

优先选用这些地点承载情绪和冲突：

- 礼堂：公共目光、学院对立、流言、长桌距离感。
- 斯莱特林地窖：冷、潮湿、家族气息、纯血圈层压力。
- 格兰芬多塔楼：友情、保护欲、哈莉的归属与窒息感。
- 图书馆与禁书区：赫敏、线索、规则边界、秘密合作。
- 魔药课教室：斯内普压迫感、德拉科熟悉场域、哈莉的警惕。
- 天文塔：坦白、未完成的告白、危险预兆。
- 黑湖：孤独、反射、沉默、冬夜情绪。
- 禁林边缘：危险、黑魔法痕迹、被迫合作。
- 医疗翼：受伤后的脆弱、探望与否认。
- 霍格莫德：短暂自由、被人看见、流言风险。

## 常用角色功能

- 罗恩：友情保护、情绪冲突、对马尔福的不信任。
- 赫敏：逻辑质询、资料检索、道德提醒、最早发现细节。
- 斯内普：压迫、洞察、双重含义、冷酷保护或试探。
- 邓布利多：宏观选择、谜语式提醒、道德重量。
- 卢修斯：家族压力、纯血政治、德拉科恐惧来源。
- 纳西莎：家族温情与控制并存，可制造复杂母子线。
- 伏地魔：恐惧中心、黑魔法源头、梦境/标记/命令/预言压力。

## 黑魔法与白魔法

### 黑魔法

黑魔法应带有腐蚀、控制、恐惧和代价。适合表现：

- 墙面残留寒意。
- 魔杖尖端出现不自然绿光。
- 伤口无法被普通治疗咒完全愈合。
- 梦境、标记、诅咒物、家族命令造成心理压力。
- 使用者变得冷、麻木、失控或短暂获得力量后付出代价。

### 白魔法

白魔法不只是“正义技能”，更适合表现意志、记忆、保护和选择：

- 守护神需要真实而坚定的记忆。
- 防护咒体现“我要保护谁”的意愿。
- 治疗咒可以暂时止血，但不能解决心理创伤。
- 缴械咒、昏迷咒、防护咒可以比杀伤咒更能体现哈莉的道德选择。

## 角色出场组合建议

### 哈莉 + 德拉科 + 罗恩

适合写友情和恋爱冲突。罗恩不应只是吵闹，他的反对来自真实历史和保护欲。让他说出一些刺痛哈莉的话，但也让他害怕她被伤害。

### 哈莉 + 德拉科 + 赫敏

适合写理性审视。赫敏可以看出德拉科行为中的矛盾，也能提醒哈莉：理解一个人不等于信任一个人。

### 哈莉 + 德拉科 + 斯内普

适合写压迫和双关。斯内普可以通过一句训斥同时警告两个人，也可以看穿德拉科的恐惧和哈莉的莽撞。

### 哈莉 + 德拉科 + 伏地魔线索

适合写关系代价。伏地魔或食死徒相关线索应迫使德拉科在家族与哈莉之间做选择，也迫使哈莉面对“相信马尔福”带来的风险。

## 常见剧情种子

- 哈莉在禁书区发现一本会自动隐藏马尔福姓氏的书。
- 德拉科收到家族命令，目标却与保护哈莉相冲突。
- 斯内普安排两人留堂清理一批被黑魔法污染的魔药材料。
- 赫敏发现哈莉的守护神记忆发生了微妙变化。
- 罗恩撞见德拉科在医疗翼外停留，却没有进去。
- 伏地魔相关梦境让哈莉看见马尔福庄园的一角。
- 天文塔上，一个防护咒只有哈莉和德拉科同时施法才稳定。
- 黑魔标记的残影出现在霍格沃茨墙面上，德拉科比任何人都先认出来。

## 避免事项

- 不要让原著角色只为男女主恋爱服务；他们应有自己的判断和动机。
- 不要把黑魔法写成单纯酷炫能力，要有代价和道德阴影。
- 不要让伏地魔线只做背景板；即使不出场，也要通过后果影响人物选择。
- 不要让德拉科轻易摆脱家族和食死徒压力。
- 不要让哈莉为了爱情放弃友情、勇气和道德核心。
