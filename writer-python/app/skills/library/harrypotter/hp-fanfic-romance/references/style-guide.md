# 中文哈利波特同人细腻文风指南

## 目标声音

使用原创中文叙事声音，不模仿任何在世作者的具体文风。整体感觉应当是：有霍格沃茨的古旧校园氛围，有魔法世界的神秘和危险，有战争阴影下的克制情绪，有家族、学院、血统与阵营带来的压力，有人物内心层次。

## 三层质感

每个重要场景至少包含三层：

1. 物理氛围：石墙、烛光、移动楼梯、画像、地窖、禁书区、黑湖、猫头鹰棚屋、魔药气味、袍角、脚步声。
2. 原著社会压力：学院敌意、马尔福家名声、救世主标签、血统政治、教授目光、朋友质疑、食死徒阴影、伏地魔恐惧。
3. 情绪矛盾：想靠近却维护骄傲，害怕被怜悯却需要帮助，用愤怒掩盖心动，用讽刺掩饰保护。

## 段落节奏

强张力段落可以采用：

1. 一个具体物件或环境细节。
2. 一个可见动作。
3. 一句只说了一半真相的对话。
4. 一个私人念头或身体反应。
5. 一句改变情绪 stakes 的收束。

示例结构：

```text
雨水顺着霍格沃茨高窗的铅条往下爬，像一道道没写完的咒文。
哈莉把魔杖攥得太紧，指节在昏暗里泛白。
“你又打算一个人去送死，波特？”德拉科说。
她本该反驳，可他没有嘲笑她的勇敢，只是把“一个人”咬得很轻。
那比任何讽刺都更难回答。
```

## 情绪潜台词示例

不要直接写：

```text
哈莉意识到自己喜欢德拉科。
```

优先写成：

```text
她本该把手抽回来。事实上，她已经想好了该用怎样冷淡的语气嘲讽马尔福多管闲事。可他的指尖冰得像刚从雪地里回来，而她忽然忘了第一句话该从哪里开始。
```

不要直接写：

```text
德拉科很担心她。
```

优先写成：

```text
“你的魔杖拿反了。”他说。
哈莉低头看了一眼，发现并没有。
可德拉科已经站到了她和那扇正在渗出黑雾的门之间。
```

## 对话规则

- 讽刺里要藏观察。
- 纠错里要藏关心。
- 沉默要回答骄傲说不出口的话。
- “波特”和“马尔福”可以保留敌意和距离；直呼名字应代表亲密、失控、恐惧或关系破裂。
- 公开场合可以恢复冷淡称呼，私下才露出裂缝。
- 德拉科不应突然深情告白；他更可能先说“别碍事”，但身体已经挡在危险前。
- 哈莉不应突然柔弱依赖；她可以接受帮助，但通常会先生气。
- 罗恩的质问要带友情和保护欲，赫敏的追问要带逻辑和洞察力，斯内普的训斥要带压迫和双关。

## 适合反复使用的母题

- 断裂又修好的魔杖。
- 雨水里反射出的绿光或银光。
- 马尔福家族戒指。
- 闪电疤痕、黑魔标记、未愈合的伤。
- 隐形衣与被注视。
- 图书馆禁书区。
- 决斗留下的细小伤痕。
- 守护神无法成形，或形态发生变化。
- 没有寄出的信。
- 魔药蒸汽显出隐藏颜色。
- 移动楼梯把两人分开，或迫使两人靠近。

## 氛围词库

可以优先使用这些类别的细节，但不要机械堆叠：

- 光：礼堂烛火、壁炉余烬、月光、幽绿反光、银色雨光、魔杖尖端的微光。
- 声：羽毛笔刮纸、远处盔甲轻响、画像窃窃私语、楼梯转动、魁地奇球场欢呼、雨声。
- 触感：冷玻璃、潮湿袍角、粗糙羊皮纸、魔杖木纹、指尖寒意、魔药瓶冰凉的瓶颈。
- 气味：旧书、药草、烟灰、潮湿石墙、蜂蜜酒、雪夜空气、魔药课地窖的苦味。
- 空间：礼堂、长廊、天文塔、斯莱特林地窖、格兰芬多塔楼、温室、图书馆、医疗翼、黑湖边、魁地奇看台、禁林边缘。

## 避免事项

- 没有铺垫的突然表白。
- 现代网络梗破坏时代和霍格沃茨氛围。
- 形容词过多但缺少动作。
- 德拉科瞬间变成温柔完美恋人。
- 哈莉为了恋爱变被动、软弱或失去主线目标。
- 罗恩、赫敏、斯内普、邓布利多等原著角色沦为单一功能工具人。
- 家族偏见、学院敌意、阵营压力被轻易解决。
- 黑魔法只作为装饰，不推动冲突也不制造道德压力。

## 润色优先级

润色时按顺序检查：

1. 人物有没有保留骄傲、防御和核心性格？
2. 原著角色和霍格沃茨元素是否自然融入？
3. 情绪有没有通过动作和对话潜台词出现？
4. 是否同时推进伏地魔/黑魔法主线和感情线？
5. 结尾是否有悬念、沉默或未完成的情绪？
