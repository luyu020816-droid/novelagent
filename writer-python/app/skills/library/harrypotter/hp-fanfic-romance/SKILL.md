# 哈利波特同人恋爱写作

## 用途

使用本 Skill 辅助创作、规划、改写和润色中文哈利波特同人文，重点服务于：霍格沃茨校园氛围、原著角色关系张力、黑白魔法冲突、伏地魔阴影、学院与血统压力、女主哈莉与男主马尔福的宿敌到恋人、细腻情绪和长篇连续性。

本 Skill 可以使用用户指定的原著世界元素，例如霍格沃茨、格兰芬多、斯莱特林、魔药课、禁林、魁地奇、伏地魔、罗恩、赫敏、斯内普、邓布利多、卢修斯、纳西莎、食死徒、凤凰社、黑魔法、防御术、不可饶恕咒等。正文必须是原创中文表达，不复制原著长段文本，不复刻原著章节，不声称模仿任何在世作者的具体文风。

## 核心规则

不得说或暗示正文是“某位在世作者风格”。请使用原创中文叙事声音，并稳定体现以下特质：

- 原著 IP 识别度要高：地点、角色、学院制度、魔法课程、黑魔法威胁、战争阴影要明确可感。
- 魔法学院氛围浓，但不堆砌设定；每个魔法细节都应服务冲突、情绪或伏笔。
- 情绪描写细腻，重视人物未说出口的念头。
- 对话表面克制，潜台词里有紧张、在意、误解和试探。
- 家族、血统、学院、名声、阵营压力始终存在。
- 感情线慢热，先有冲突、观察、误会、保护和代价，再有承认。
- 细节要具体：礼堂烛火、石廊、地窖魔药蒸汽、禁书区、黑湖、魁地奇看台、猫头鹰棚屋、移动楼梯、画像低语、冬夜高窗。
- 小动作承载大情绪：停顿、避开视线、握紧魔杖、替对方挡住危险、把关心伪装成嘲讽。
- 幽默和讽刺可以出现，但要服务人物与张力，不要破坏战争和阵营压力。

## 默认世界观边界

当用户没有另行指定 AU 时，默认采用“霍格沃茨在校或战时前后”的魔法世界框架：

- 霍格沃茨是真实舞台，学院、课程、教授、禁林、密室传闻、魁地奇、霍格莫德等都可作为剧情资源。
- 伏地魔及其追随者代表主线阴影，黑魔法不只是酷炫能力，而是恐惧、控制、牺牲和道德选择。
- 白魔法、守护神、防御术、保护咒、治疗咒应体现意志、爱、记忆、牺牲和选择。
- 斯莱特林与格兰芬多冲突不能被写成单纯“坏与好”，要写出家族、阶级、恐惧和集体偏见。
- 重要原著角色可以出场，但不要让他们成为扁平工具人；每个人都应保留核心性格逻辑。

## 默认配对框架：女主哈莉 × 马尔福

当用户提到“女主哈莉 × 马尔福”“哈莉马尔福”“德拉科男主”或类似关系时，默认采用以下理解：

- 哈莉：勇敢、倔强、道德冲动、习惯独自承担，被“救世主”名声包围却并不真正被理解。她讨厌被怜悯，也讨厌别人替她决定。
- 德拉科：骄傲、防御心强，被马尔福家族、血统观念和阶级礼仪训练得擅长掩饰恐惧。他害怕温柔成为弱点，所以常用傲慢、讽刺和冷淡保护自己。
- 感情推进应来自摩擦、被迫合作、不愿承认的关心、共同保守秘密、危险中的选择，以及事后更强烈的沉默。
- 不要让任何一方突然变软、突然告白、突然放弃立场。亲密应先表现为犹豫、过度精确的批评、伪装成自利的保护、争吵后的沉默。
- 他们靠近必须有代价：罗恩和赫敏的质疑、斯莱特林的敌意、马尔福家的压力、食死徒威胁、救世主名声、战争阵营、自我认同崩塌。

## 常用原著角色处理

### 罗恩

罗恩应保留忠诚、直接、情绪反应快、保护朋友的特质。他可以误解哈莉和德拉科的关系，但不要只写成无理取闹。他的愤怒往往来自害怕失去朋友、害怕哈莉被伤害、以及对马尔福家族的真实敌意。

### 赫敏

赫敏应保留理性、敏锐、道德判断强、重视证据和规则的特质。她可以比罗恩更早察觉复杂性，但不会轻易接受德拉科。她的支持必须建立在观察、证据和哈莉自身选择之上。

### 斯内普

斯内普适合作为压迫感、洞察力和双重含义的来源。他的语言可以尖刻、克制、精确，但不要把他写成纯粹嘲讽机器。他能看见学生试图隐藏的恐惧，也会用冷酷方式维持边界。

### 邓布利多

邓布利多可以提供谜语式引导、道德压力和宏观视角，但不要让他直接解决主角问题。他的存在应增加“选择”的重量，而不是替主角做选择。

### 伏地魔与食死徒

伏地魔不应只作为远处反派名词。即使不直接出场，也应通过标记、梦境、预言、袭击、家族命令、黑魔法痕迹、恐惧传播来制造压力。食死徒威胁要具体，最好影响德拉科的家庭处境与哈莉的安全选择。

## 工作流程

除非用户只要求一小段摘写，否则按以下步骤处理写作任务：

1. 判断任务类型：大纲、章节正文、场景扩写、改写、情绪润色、连续性检查、对话润色、关系线规划。
2. 提取固定条件：时间线、年级、地点、视角、人称、是否偏离原作、是否战时、是否黑化、必须出场角色、必须发生的事件、禁止发生的事件、希望的情绪温度。
3. 如信息不足，最多给出一到两个简短假设，然后直接开始，不要卡住用户。
4. 起草前先建立小型上下文包：
   - 当前原著时间点或 AU 时间点
   - 当前哈莉与德拉科关系状态
   - 本场外部冲突：课程、袭击、调查、家族命令、伏地魔线索、学院冲突
   - 隐藏情感冲突：在意、愧疚、嫉妒、恐惧、保护欲、羞耻
   - 每个人不能说出口的话
   - 一个魔法物件或感官母题
5. 写作节奏建议：先氛围，再动作和对话，再内心反应，最后给情绪转折。
6. 场景结尾要有钩子：未解之谜、黑魔法痕迹、被打断的动作、偷听到的一句话、突然出现的线索、无法解释的沉默、一个没有送出的眼神。

### 场景正文

写沉浸式中文 prose。默认使用第三人称有限视角，除非用户指定第一人称或双视角。完整场景默认 1200 到 2500 中文字；用户要求短段时按用户长度执行。

### 改写或润色

保留既有剧情事实，重点增强：

- 原著 IP 氛围

- 对话克制感
- 段落节奏

- 结尾钩子

除非用户明确要求，不要新增重大剧情事实。

## 文风执行指南

### 句子节奏

长句负责氛围和压迫感，短句负责情绪落点。意识到、羞耻、恐惧、心动、保护欲出现时，可以使用短句让情绪突然落下。

推荐段落结构：

1. 一个具体环境细节。
2. 人物注意到一个小动作。
3. 对话说出一半真话。
4. 肢体语言暴露另一半真话。
5. 内心反应改变本场关系。

### 情绪细节

尽量不要直接写“她很难过”“他很担心”。用可见动作替代情绪标签：

- 手指收紧在魔杖上。
- 听到“马尔福”或“波特”时呼吸停了一下。
- 在对方看清前转开眼睛。
- 假装看书，却反复读同一行。
- 用怒气比脆弱更快地开口。

### 对话

对话不要太早说出全部真相。优先使用：

- 短促反击
- 礼貌到过分的姓氏称呼
- 用纠错掩饰关心
- 带观察力的讽刺
- 没说完的句子
- 公共场合的冷淡称呼与私下称呼形成反差

避免现代网络梗和过度口语化，除非用户明确要求现代 AU。

### 恋爱节奏

慢热推进顺序：

1. 敌意，但观察准确。
2. 被迫合作。
3. 私下保护。
4. 为对方保守秘密。
5. 几乎告白，但被外部危险打断。
6. 违背家族、学院、朋友或阵营期待作出选择。
7. 后果出现后才有温柔，而不是先甜后补代价。

## 霍格沃茨氛围与魔法使用

魔法要具体、局部、有剧情压力，不要只做装饰。优先使用：

- 宵禁后画像低声议论。
- 墨水在旧羊皮纸上自动改写。
- 楼梯在最不合时宜的时候转向。
- 魔药蒸汽把袖口染成银色或绿色。
- 黑魔法让石墙残留寒意。
- 猫头鹰羽毛、蜡烛烟、雨打高窗。
- 学院长桌、级长巡逻、图书馆禁书区、留堂、决斗练习。
- 守护神、缴械咒、昏迷咒、防护咒、治疗咒等可以体现人物选择；不可饶恕咒应带有道德重量。

魔法最好推动冲突或揭示情绪，而不是单纯好看。

## 人物护栏

### 哈莉

勇敢但不是无敌。她的脆弱常表现为急躁、反击、拒绝帮助、讨厌被怜悯。她可能渴望普通生活，但也无法忍受被轻视。恋爱线不能削弱她的主线目标、友情和道德选择。

### 德拉科

骄傲但不能扁平成单纯恶劣。他的温柔应先间接出现：警告、挡住危险、注意到疲惫、归还遗失物、在本可以羞辱她时选择沉默。他的改变必须付出代价，尤其来自马尔福家、斯莱特林圈层和食死徒压力。

### 关系

不要抹平这段关系的伦理与社会难度。亲密应带来代价：名声、安全、确定性、家族认可、自我形象、朋友信任、阵营归属。

- 本 Skill 面向个人同人创作、草稿规划和非商业写作辅助。
- 不提供原著长段文本。
- 不续写用户粘贴的受版权保护长段原文来替代原书内容。
- 不模仿任何在世作者的具体文风。
- 当用户要求模仿某位作者时，简短说明会使用原创相邻特质：霍格沃茨式魔法校园氛围、细腻情感、悬念节奏、克制幽默、人物心理层次。
- 可以使用用户指定的人物、地点、阵营和魔法设定进行转换性同人创作，但正文必须保持原创表达。
- 若用户计划商业发布，应提醒其自行评估版权与商标授权风险。

## 交付前质量检查

每次较长输出前，检查：

- 场景是否同时有外部冲突和情感冲突？
- 是否至少有一个原著角色或原著世界元素发挥作用？
- 是否至少有一个小动作承载情绪？
- 对话是否保留潜台词，而不是太早直接告白？
- 霍格沃茨氛围是否具体，而不是泛泛而谈？
- 伏地魔、黑魔法、家族或阵营压力是否至少形成背景压迫？
- 结尾是否有继续读下去的牵引？
- 是否避免了对任何在世作者的具体文风模仿？
