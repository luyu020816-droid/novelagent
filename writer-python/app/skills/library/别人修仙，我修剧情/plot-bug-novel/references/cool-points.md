# 爽点脑洞手册

## 1. 这个题材的爽点本质

普通爽文：别人瞧不起主角，主角变强打脸。

本题材：别人瞧不起主角，主角发现“你们这段剧情写崩了”，然后现实被迫承认。

爽点来自三种体验：
1. **认知优势**：主角看见别人看不见的原文矛盾。
2. **公开处刑**：越严肃、越权威的人设崩得越响。
3. **逻辑反杀**：反派不是被拳头打败，而是被自己的设定漏洞打败。

## 2. 爽点公式

### 标准公式

压迫场面 → 权威人物立人设 → 主角发现矛盾 → 对方继续装 → 主角轻轻一问 → 世界校验 → 人设崩塌 → 更大真相露头。

### 搞笑公式

全场都在严肃装逼 → 主角像产品经理一样提需求 → 世界真的弹出报错 → 大人物破防 → 主角本人也懵。

### 高燃公式

配角被剧情判死 → 主角发现死亡逻辑不成立 → 顶着天道压力提出校验 → 世界试图压制 → 主角补齐证据链 → 原剧情失效 → 配角获得自主命运。

## 3. 爽点分类

### A. 身份漏洞

某人身份前后矛盾。

例子：
- 已死老祖还在主位上喝茶。
- 说自己是孤儿的天骄，家族族谱里有九个爹。
- 正道圣子前文说从未离宗，魔域通缉令上却贴着他的画像。
- 魔尊说自己无情无欲，账本里每个月给孤儿院打灵石。

爽点：扒掉伪装，打破权威。

### B. 时间线漏洞

事件发生顺序不成立。

例子：
- 某人十六岁成名，但他的成名战发生在二十年前。
- 秘境百年开启一次，三个月开了三次。
- 祖师三百年前飞升，却在两百年前亲手写了门规。

爽点：用时间线拆穿谎言。

### C. 规则漏洞

世界规则前后不一致。

例子：
- 功法说必须童子身修炼，修成者却有八个孩子。
- 神器说非女主不可触碰，拍卖会上人人上手摸。
- 丹药设定只能救命一次，某反派吃了七颗。

爽点：把所谓天道规则变成可查文档。

### D. 物品漏洞

法宝、丹药、功法、地图的设定冲突。

例子：
- 断剑前文被炼成剑丸，后文又完整出现。
- 丹方缺一味主药，却被丹师量产。
- 地图标注“禁地无人归来”，旁边有小吃摊和客栈。

爽点：主角靠校验捡漏、识假、反坑。

### E. 人设漏洞

人物性格与行为冲突。

例子：
- 冰山圣女遇事疯狂发小作文。
- 无情剑尊偷偷写恋爱日记。
- 阴险反派每次都把计划当众讲完。
- 慈悲方丈的储物袋里全是高利贷欠条。

爽点：让角色“装不下去”。

### F. 动机漏洞

反派行动理由站不住。

例子：
- 反派说灭门是为了报仇，但仇人早已死在前文。
- 女配说嫉妒女主夺爱，但她和男主根本没见过。
- 长老说为了宗门大义，结果所有收益流向自己私人洞府。

爽点：将狗血动机拆成利益链。

### G. 版本冲突

同一个角色来自不同稿件版本。

例子：
- 戒指老爷爷一会儿是剑尊，一会儿是丹圣，一会儿是魔族卧底。
- 女主在早期稿是退婚女，在新版稿是青梅竹马，在续写稿是反派白月光。
- 宗门历史有三个版本，每个版本都有人信。

爽点：一修正就炸出隐藏群像。

## 4. 让爽点不无脑的设计

### 每个爽点都要有代价

- 主角暴露能力，被强者盯上。
- 修正一个小 bug，引出更大 bug。
- 救下一个人，剧情开始找替代牺牲品。
- 公开揭穿真相，主角得罪既得利益者。

### 反派要聪明

反派应该会：
- 封锁证据。
- 制造替代解释。
- 借群众心理反咬主角。
- 利用规则漏洞坑主角。

主角赢得越难，爽感越足。

### 校验不等于许愿

主角不能说“我觉得我应该是仙帝”就变仙帝。

他只能基于文本矛盾提出校验。现实修正的是“前后不一致”，不是满足愿望。

## 5. 原创脑洞库

### 脑洞 1：天骄榜版本没更新

天骄榜第一已经死了三年，但榜单仍每天给他涨声望。主角发现，榜单不是记录实力，而是在给某个死人续命。

### 脑洞 2：宗门门规有两个作者

同一条门规前半句讲仁义，后半句讲灭口。主角校验后发现门规被魔道续写过。

### 脑洞 3：秘境是废稿回收站

所有被作者删掉的角色、没用上的法宝、废弃地图都被扔进秘境。秘境怪物不是妖兽，是“未采用设定”。

### 脑洞 4：反派不是反派，是被剧情强制标红

某人头顶一直显示“反派”，但他做的事都在救人。主角发现他被续写者恶意改了阵营标签。

### 脑洞 5：天劫是自动审核系统

天劫不是惩罚修士，而是在审核角色是否符合当前版本设定。不符合就劈。

### 脑洞 6：女主光环是补丁包

女主每次遇险都能触发奇遇，是因为她身上装了世界补丁。主角要分辨哪些奇遇是合理成长，哪些是强行保送。

### 脑洞 7：老爷爷群聊

戒指里的老爷爷不是一个，而是多个版本残魂。剑尊、丹圣、阵祖、魔尊天天吵架，像工作群里四个前任负责人互相甩锅。

### 脑洞 8：剧情回滚日

每月十五，世界会尝试回滚到原剧情关键节点。主角必须提前找出回滚点，否则所有努力白费。

### 脑洞 9：反派死前独白保护机制

只要反派开始讲三页独白，世界会给他无敌保护。主角破解方式：强行打断，要求他提供摘要。

### 脑洞 10：上界其实是编辑部

所谓上界仙人，实则掌握更高版本权限。他们不是修为高，而是能改设定。

## 6. 章末钩子类型

- **反向真相**：被修正的人不是敌人，真正敌人坐在旁边。
- **更大漏洞**：刚修好一个 bug，系统提示发现十七处连锁冲突。
- **人物代价**：主角救的人突然说：“你不该救我，我死了才是封印条件。”
- **权限诱惑**：主角获得改稿权限，但必须删掉一段自己的记忆。
- **剧情追杀**：系统提示“剧情惯性已锁定宿主”。
- **搞笑钩子**：老爷爷三魂同时开口：“我才是正版。”

## 7. 爽点避坑

不要让主角每章都只是说一句话，然后对方爆炸。要变化：
- 有时靠公开质问。
- 有时靠收集证据。
- 有时故意不修，让 bug 反噬敌人。
- 有时修错一半，制造更大混乱。
- 有时为了救人，必须承认一个错误设定。
