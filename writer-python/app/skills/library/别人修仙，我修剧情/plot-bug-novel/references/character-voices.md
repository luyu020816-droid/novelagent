# 人物口吻手册

## 1. 林澈：主角口吻

定位：网文编辑/校对穿越者，职业病发作型主角。聪明但不油，怕死但敢刚，吐槽精准。

### 语言特征

- 句子偏短。
- 先观察，再提问。
- 不主动装逼，常用“我有个问题”“等等”“这不对”。
- 关键时刻语言变冷。

### 日常口吻

- “我先确认一下，你们这里死而复生算常规操作吗？”
- “别急，我不是说你假，我只是说你和前文不太熟。”
- “这事儿怎么说呢，像是有人改稿改到一半去吃饭了。”

### 危急口吻

- “退后。”
- “别碰那块碑。”
- “这段剧情在找替死鬼。”
- “现在不是争面子的时候，谁还记得原本的门规？”

### 高燃口吻

- “如果她的死只是为了推动剧情，那这段剧情今天就到此为止。”
- “校验。”
- “把真正的版本调出来。”
- “这不是命，是错字。”

### 内心弹幕

- “完了，我好像把自己校进主线了。”
- “这老祖掉马的速度，多少有点不尊重假发。”
- “他笑得越自信，我越觉得他文档没读完。”

## 2. 校验系统口吻

定位：冷静、机械、带一点缺德幽默。不要话痨，不做保姆，不发神级奖励。

### 标准提示

- 【检测到设定冲突。】
- 【正在比对原文记录。】
- 【冲突等级：乙等。】
- 【校验通过。现实开始修正。】
- 【校验失败。宿主被判定为恶意挑刺。】

### 冷幽默提示

- 【建议宿主不要在对方拔剑后继续解释逻辑。】
- 【当前剧情惯性较强，逃跑成功率低于嘴硬成功率。】
- 【该角色未死亡，只是作者描述过于阴间。】
- 【修正成功。副作用：你更像幕后黑手了。】

### 禁止

- 不要像传统系统一样“叮！奖励神级功法”。
- 不要替主角做全部判断。
- 不要解释过长，保持提示音质感。

## 3. 沈清寒：退婚未婚妻/女主口吻

定位：不是纯恶毒女。她可以高傲，但要有复杂性：家族压力、错误记忆、被剧情推着走。

### 前期口吻

- 冷淡、克制、讲体面。
- 以为自己做的是正确决定。

例：
- “林澈，今日之事，我不想闹得太难看。”
- “你我早已不是同路人。”
- “把婚书还我，至少还能保住最后一点体面。”

### 动摇口吻

- 句子变短。
- 开始追问真相。

例：
- “你怎么知道老祖三年前……”
- “不对，我记得……我为什么会记得他还活着？”
- “林澈，我刚才说的话，不全是我想说的。”

### 后期口吻

可以从退婚女转为复杂盟友。不要让她秒跪舔。

例：
- “我欠你一个解释，但不是现在。”
- “如果我的记忆也被改过，那我会亲手查清楚。”

## 4. 林家长老口吻

定位：传统权威，重规矩，重脸面。可有私心，但不要全员智障。

### 压迫口吻

- “放肆！”
- “祖堂之上，岂容你胡言乱语！”
- “林澈，你若还有半分林家血性，便莫要丢人现眼。”

### 破防口吻

- “这……此事自有隐情。”
- “族谱暂时不便翻阅。”
- “老夫不是心虚，是祖宗规矩不可轻动。”

### 喜剧点

长老最怕失去体面。让他越圆越崩。

## 5. 魔道护法/反派口吻

定位：聪明、自信、有压迫感。不是低级嘴臭反派。

### 登场口吻

- “你很聪明，可惜聪明人通常死得更快。”
- “有些真相，知道的人越少，世界越安稳。”
- “你不是第一个看见裂缝的人，但你会是最短命的那个。”

### 被拆穿口吻

- “你凭什么能看见？”
- “不可能，那一段早该被删了。”
- “谁给你的校验权限？”

注意：这类话可以暗示他知道世界有版本问题。

## 6. 戒指三魂口吻

### 剑尊残魂

高冷、惜字如金、爱装。

- “剑出，万法寂。”
- “少年，莫听他们聒噪，修剑即可。”
- “丹道误人。”

### 丹圣残魂

讲养生、讲细节、像老中医。

- “先把脉。”
- “剑修都短命，听我的，先补气血。”
- “你这不是废柴，是长期营养不良加剧情迫害。”

### 魔尊残魂

嘴毒、现实、懂阴谋。

- “两个老东西都别装了，你们上一版也没活到大结局。”
- “拜师？先问问他们有没有售后。”
- “小子，想活命就别当好人，当好人容易被作者拿去献祭。”

三魂组合的喜剧效果：像一个吵架群聊。

## 7. 群众口吻

群众要承担信息扩散、误解升级、喜剧反应。

### 传统群众

- “他疯了吧，竟敢质疑老祖？”
- “等等，族谱上好像真有这事……”
- “我刚才没笑，我只是嘴角抽筋。”

### 外门弟子

更接地气：
- “我靠，盘口变了。”
- “这瓜保熟吗？”
- “林师兄这是把老祖开盒了？”

不要让所有人都说现代词。外门弟子可以少量承担网感。

## 8. 上界使者/续写者口吻

定位：高维压迫，像掌握规则的人。

### 上界使者

- “下界之人，不该质疑版本。”
- “稳定比真相重要。”
- “你修补的不是漏洞，是秩序。”

### 续写者

可以更冷酷：
- “人物痛苦，读者才会继续看。”
- “你救下一个配角，就要补上另一个冲突。”
- “故事不需要每个人合理，只需要足够刺激。”

主角与续写者的对话要有主题高度，但不要说教过重。
