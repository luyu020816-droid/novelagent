# 搞笑与网感表达手册

## 1. 目标语气

偏搞笑、偏网感，但不是每句话都玩梗。

目标效果：
- 读者觉得主角脑回路清奇。
- 修仙世界很严肃，主角的现代表达形成反差。
- 笑点来自场景和逻辑，而不是硬塞网络流行语。

关键词：离谱、破防、绷不住、版本管理、bug、补丁、回滚、工单、甲方、外包、客服、权限、后台、热修复、强制更新、人设没对齐。

## 2. 网感使用原则

### 少量精准

一章中高强度网络词不要超过 3-5 处。否则会油。

### 用在心理吐槽和主角口吻

不要让所有古代人都说现代网络词。古代人可以误解这些词。

示例：
主角心里：
“这剧情已经不是崩了，这是端着锅从悬崖上跳下去了。”

古代人反应：
“版本管理是何等秘术？”

### 严肃场景中先收住

人物生死、情感爆发、重大牺牲时，网络梗要降频。

## 3. 搞笑来源

### A. 现代职业语言撞修仙

- “你们这个宗门制度，属于祖传屎山。”
- “老祖复活这种大版本更新，不发公告吗？”
- “天道能不能别静默安装补丁？”
- “你这个反派动机像临时开会拍出来的。”

### B. 主角认真提离谱问题

场面越严肃，问题越像质检表，越好笑。

- “请问您这个死而复生有审批流程吗？”
- “百年秘境三个月开三次，你们是办季卡了吗？”
- “你说你从未离宗，那魔域通缉令上的证件照是怎么回事？”

### C. 群众误解现代词

主角说 bug，别人以为是虫蛊。

例：
“此人竟能看见天道之虫！”
“不是虫，是 bug。”
“果然是上古异虫！”

### D. 系统冷幽默

系统不要话痨，但提示可以冷。

- 【校验失败：该长老未死亡，只是气色确实不太行。】
- 【冲突等级：甲等。建议宿主先找出口。】
- 【剧情惯性增强。温馨提示：跑直线会死得比较快。】

### E. 大人物破防

不要写反派像小丑，而是让他维持体面失败。

- 他想冷笑，嘴角却像卡了加载条。
- 长老沉默三息，决定先把族谱合上。
- 魔道护法第一反应不是杀人，而是低头检查自己的脸还在不在。

## 4. 主角吐槽风格

推荐：短、准、带职业病。

### 好的吐槽

- “这不是伏笔，这是遗留问题。”
- “你们这世界没有天道，只有没合并干净的草稿。”
- “这段剧情不能播，逻辑审核过不了。”
- “他不是隐藏大佬，他是版本冲突。”

### 不好的吐槽

- 大段解释网络梗。
- 每句话都“笑死、绷不住、家人们谁懂啊”。
- 主角疯狂嘲讽弱者。
- 在生死场景插无关段子。

## 5. 网络流行词使用清单

### 可以用，但要克制

- 离谱：适合内心吐槽。
- 破防：适合反派或群众反应。
- 绷不住：适合搞笑段落。
- 人设崩了：主题词，常用但要变化表达。
- 开盒：慎用，现代感强，适合玩笑，不适合严肃剧情。
- 这合理吗：适合主角质疑。
- 版本更新/回滚/补丁：非常适合本题材。
- 工单/客服/后台：适合天道、系统、上界相关。

### 尽量少用

- 家人们谁懂啊：容易出戏。
- yyds、绝绝子：过时感强，慎用。
- 芭比Q：容易显油。
- 太多英文缩写：会破坏修仙质感。

## 6. 段子节奏

### 三拍式笑点

1. 正常预期。
2. 继续加重预期。
3. 主角用现代逻辑拆掉。

例：
长老：“秘境百年一开，乃祖训所定。”
护法：“天地异变，提前开启，也并非没有先例。”
林澈：“三个月开三次，这不叫天地异变，这叫秘境办了健身卡。”

### 延迟笑点

先让读者以为主角要装逼，结果他在想逃跑。

例：
所有人都以为林澈沉默，是在酝酿惊天反击。
只有林澈知道，他正在计算从主位到大门的最短逃生路线。

### 反差笑点

严肃术语 + 现代小事。

例：
“此乃天命纠偏。”
“说人话。”
“剧情不让你下班。”

## 7. 搞笑不能伤害爽点

当场景需要强爽，笑点要成为爽点助推器：
- 反派破防可以搞笑。
- 群众反应可以搞笑。
- 系统提示可以搞笑。
- 主角在关键反击时不要变成说相声。

主角正式发力时，语言要短：
“校验。”
“回滚。”
“把原文调出来。”
“这段，不算。”

## 8. 示例句库

- “你别急着灭我满门，你先解释一下你上章为什么还在闭死关。”
- “这不是上古秘辛，这是作者忘了。”
- “你们管这叫天机不可泄露？我管这叫文档缺失。”
- “此地禁止斗法，但允许剧情杀是吧？”
- “老祖，您这个复活有点不尊重前文。”
- “我不是不信天道，我是不信没有版本号的天道。”
- “你的人设正在冒烟。”
- “别装了，你这个反派动机临时得像会前五分钟补的 PPT。”
