# 核心设定手册

## 1. 一句话定位

主角穿进一个被烂尾、重写、续写、外包改稿搞崩的修仙爽文世界。别人靠灵根、血脉、法宝、老爷爷修炼，主角靠发现世界设定漏洞、提出校验、逼迫现实修正来活下去。

核心爽感不是“我拳头更大”，而是“你的人设、历史、时间线、动机、规则前后对不上”。

## 2. 世界本质

这个世界表面是传统修仙大陆，底层却像一份被反复修改的小说稿：

- 早期稿：废柴退婚、坠崖、戒指老爷爷、宗门大比。
- 中期稿：天骄争霸、秘境夺宝、魔道入侵、女主觉醒血脉。
- 后期稿：上界降临、轮回真相、天道阴谋、世界重启。
- 烂尾稿：伏笔没收、死人复活、神器设定变动、反派动机崩坏。
- 续写稿：为了刺激读者，强行加狗血、黑化、灭门、误会、献祭。

现实由这些版本叠加而成。普通人只觉得“天道难测”，主角能看到“作者忘了前文”。

## 3. 主角身份建议

优先人设：网文编辑、校对、剧情策划、剧本杀主持、游戏数值策划、文档管理员。

推荐默认：**网文编辑/校对出身**。

优势：
- 合理解释他为什么会记设定、抓逻辑、看时间线。
- 自带吐槽欲，但可以控制成职业病，不是纯杠精。
- 与“修补剧情”主题强绑定。

主角性格：
- 不是龙傲天式狂拽，而是“想低调，但职业病不允许”。
- 表面冷静，内心弹幕很多。
- 怕死、谨慎、会怂，但关键时刻敢指出漏洞。
- 嘴不贱到讨厌，吐槽要准、短、狠。

主角口头禅方向：
- “先别急着杀我，你这个设定没对齐。”
- “我不是针对你，我是针对这段剧情。”
- “你们修仙界最大的问题不是魔道，是版本管理。”
- “这不是天意，这是前后文冲突。”

## 4. 能力体系：设定校验

### 基础能力：看见原文残影

主角能在关键场景中看到与当前现实相关的原文片段，例如：

> 【林家老祖，三年前渡劫失败，尸骨无存。】

这不是完整剧透，而是碎片。碎片越关键，越容易触发风险。

### 主动能力：设定校验

主角指出“当前现实”和“原文设定”的矛盾，世界会判定是否成立。

流程：
1. 主角发现矛盾。
2. 主角在现实中提出质疑。
3. 校验器比对原文、现实、因果链。
4. 判定冲突等级。
5. 现实修正，但修正方式未必按主角预期。

示例：
- 主角问：“老祖，您三年前不是死了吗？”
- 校验通过。
- 现实不一定直接让老祖死亡，而是揭示：现在的老祖是魔道护法假扮。

### 权限等级

1. **旁注级**：发现小错，如称号、衣着、时间细节。效果偏搞笑或信息提示。
2. **校对级**：修正人物状态、身份、物品归属、境界矛盾。
3. **改稿级**：让隐藏真相浮出水面，修改局部剧情走向。
4. **版本级**：识别不同稿件版本冲突，选择保留哪个版本。
5. **终稿级**：接触世界底层逻辑，能挑战剧情意志。

不要开局给高权限。升级要靠主角解决重大剧情 bug。

## 5. 限制和代价

必须有约束，否则会变成无脑外挂。

### 校验失败惩罚

如果主角判断错了：
- 扣寿元。
- 暂时失去原文视野。
- 被剧情标记为“恶意挑刺”。
- 现实把他的质疑反向合理化，让他社死。

示例：
主角质疑某长老假死，校验失败。系统提示：
> 【校验失败。该长老只是睡眠质量极差，看起来像死了。】
现场所有人盯着主角，主角当场脚趾施工。

### 证据门槛

重大漏洞不能靠一句“我觉得不对”修正。主角需要：
- 原文残影。
- 现实证据。
- 逻辑链。
- 合适公开场合。

### 修正副作用

世界修正后会产生新麻烦：
- 冒牌老祖暴露，背后魔道组织盯上主角。
- 传承老爷爷被拆成三魂，天天吵架。
- 主角救下一个本该死的人，剧情为了补死亡名额，开始找替死鬼。
- 修复小 bug 后，引出更大的版本冲突。

## 6. 长线敌人

### 第一层：人物敌人

魔道护法、退婚未婚妻背后的家族、宗门长老、天骄少主、上界使者。

### 第二层：剧情惯性

剧情会尝试把偏离的故事拉回原轨道：
- 退婚没成，就安排第二次羞辱。
- 主角没坠崖，就让地面追着他裂。
- 反派没黑化，就制造新的误会逼他黑化。

### 第三层：剧情意志

它不是神，而是一种叙事纠偏程序。目标是维持“爽文套路能继续发生”。

表现：
- 强行制造冲突。
- 屏蔽部分原文片段。
- 给配角灌输错误记忆。
- 把主角标记成世界漏洞。

### 第四层：续写者

终极反派可以是“续写者”：一个世界外的改稿者，只追求刺激、冲突、流量，不在乎人物是否崩坏。

主角最终对抗的不是某个魔尊，而是“把所有人当剧情耗材的写烂者”。

## 7. 主题内核

表层：搞笑爽文，靠挑 bug 打脸。

中层：反套路，吐槽网文烂尾、强行狗血、设定崩坏。

深层：人物反抗被强行安排的命运。每个人不该只是推动爽点的工具人。

不要过度说教。主题要藏在剧情里：被修正的人物重新获得选择权，读者自然能感到高级。

## 8. 禁止写偏

避免把故事写成：
- 普通系统升级文。
- 单纯打脸退婚文。
- 主角无限剧透碾压。
- 段子合集，没有主线压力。
- 纯吐槽作者，缺少人物情感。

每个设定漏洞都必须推动人物关系、世界真相、或主线风险。
