# 场景与大环境手册

## 1. 世界气质

这是修仙爽文世界，但表面正经、底层离谱。所有人都一本正经地活在 bug 里。

写场景时要有双层感：
- 第一层：传统修仙氛围，宗门、灵峰、剑气、丹炉、天劫、法阵。
- 第二层：隐藏的文本错误感，时间线错位、设定补丁、版本冲突、工具人命运。

不要让世界像纯喜剧小品。越严肃的环境，主角一句“你这设定对不上”才越好笑。

## 2. 社会大环境

### 修仙界公开规则

- 灵根决定修行起点。
- 宗门掌握资源分配。
- 世家联姻维持利益。
- 天骄榜、丹榜、器榜、功法榜影响声望。
- 正魔两道表面敌对，暗地互相渗透。
- 上界传说压迫下界，形成阶级焦虑。

### 隐藏规则

- 大人物常被不同版本设定覆盖。
- 越接近主线，越容易发生逻辑冲突。
- 人气高的人物更容易被剧情保护。
- 工具人容易被剧情牺牲。
- 老设定与新设定冲突时，现实会短暂卡顿。

### 群众心理

群众不是傻子，但他们习惯了“天道玄妙”。所以看到离谱现象时，他们会自己圆：
- “老祖复活？一定是逆天秘法。”
- “秘境三个月开三次？说明天地大变。”
- “死去的剑尊又出现？大能布局，不可揣测。”

主角的独特性在于：他不帮世界圆，他直接问“你前文不是死了吗？”

## 3. 高复用场景库

### 退婚大厅

功能：开局打脸、身份暴露、设定校验首秀。

环境关键词：
- 正厅、祖宗牌位、婚书、茶盏、族人窃笑、未婚妻冷脸、长老压迫。

可藏 bug：
- 已死老祖在场。
- 婚书上的日期与两人年龄对不上。
- 未婚妻口中的退婚理由与原文动机冲突。
- 林家祖训前后版本不同。

情绪重点：
- 主角醒来先懵，再自保，再职业病发作。
- 群众从嘲讽到沉默，再到惊恐。
- 未婚妻从高高在上到被迫重新评估主角。

### 宗门大比

功能：爽点密集，适合连续反转。

环境关键词：
- 演武台、观礼席、长老席、天骄榜、赌盘、护山大阵。

可藏 bug：
- 某天骄的年龄和成名时间冲突。
- 某功法说不可传外人，却人人都会。
- 裁判长老前文说闭死关，现在主持比赛。
- 比赛规则临时变动，但古碑上刻着旧规则。

写法：
- 先让对手装到位。
- 再让主角发现不对。
- 不要立刻爆，先让观众情绪堆高。
- 公开校验时让整个演武场一起破防。

### 秘境入口

功能：探索世界历史、制造版本冲突。

可藏 bug：
- 秘境百年开启一次，但近期频繁开启。
- 地图标注与入口位置不一致。
- 石碑记载“无人归来”，却有大量攻略流传。
- 守门兽的种族设定和外貌冲突。

喜剧点：
主角像查旅游攻略一样吐槽秘境：
“百年一开，三个月三次，你们这秘境是办会员卡了吗？”

### 拍卖会

功能：物品设定修正、身份揭露、智斗。

可藏 bug：
- 神器前文说不可损毁，现在成了残片。
- 丹药效果前后矛盾。
- 拍卖师介绍的来历与原文不符。
- 某买家叫价的钱数超过其家族资产设定。

爽点：
主角不是靠钱砸，而是指出拍品设定错误，逼出真货或假货。

### 审判台/宗门问罪

功能：主角被围攻时反向翻盘。

可藏 bug：
- 罪名时间线不成立。
- 证人的身份前后矛盾。
- 宗规被改过版本。
- 执法长老本该没有权限。

情绪重点：
- 压迫感要足，让读者觉得主角真危险。
- 主角先不急着反驳，等对方把话说满。
- 反转时让证据链一层层崩。

### 天劫现场

功能：高燃、荒诞、世界底层规则曝光。

可藏 bug：
- 天劫等级与修为不匹配。
- 雷劫对象错了。
- 天道审判词引用了不存在的罪名。
- 天劫在追着主角修剧情。

喜剧点：
主角抬头看雷云：
“不是，你劈我之前能不能先把工单号报一下？”

## 4. 场景压力设计

一个漏洞不能凭空出现。要让它被揭开时有压力：

- **性命压力**：主角再不指出就会死。
- **名誉压力**：主角被污蔑，必须找出逻辑漏洞。
- **资源压力**：宝物即将被抢走，必须校验归属。
- **情感压力**：某配角要被剧情牺牲，主角必须推翻原设定。
- **公共压力**：人越多，打脸越爽，但风险也越大。

## 5. 环境描写原则

不要写成大段说明书。场景应服务剧情。

优先写：
- 哪些东西压迫主角？
- 哪些细节暗示 bug？
- 哪些群众反应放大爽点？
- 哪些环境变化说明世界正在修正？

示例：
- 茶盏在桌上轻轻一跳，像有人按下暂停键。
- 祖宗牌位上的名字忽明忽暗，其中一个名字被墨迹慢慢划掉。
- 大厅里所有人都还保持着嘲笑表情，只有那个“老祖”的脸在一点点变年轻。

这种细节比直接说“世界开始修正”更有画面感。
