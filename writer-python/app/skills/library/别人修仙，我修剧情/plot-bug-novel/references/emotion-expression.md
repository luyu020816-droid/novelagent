# 情绪表达手册

## 1. 总原则：别只说情绪，要让读者看见情绪

弱写法：
- 林澈很震惊。
- 未婚妻很尴尬。
- 长老很愤怒。

强写法：
- 林澈盯着主位上的老祖，手指把椅背扣出一道浅痕。
- 沈清寒想把退婚书收回去，手却停在半空，像突然忘了自己刚才有多硬气。
- 长老的胡子抖了两下，茶盏盖子被他按得咔一声裂开。

写情绪时优先使用：动作、停顿、语气、身体反应、视线、环境反馈、群众反应。

## 2. 爽文情绪链

### 经典链条

被压 → 憋屈 → 发现破绽 → 忍住不说 → 对方继续装 → 主角轻轻点破 → 全场反应 → 现实修正 → 情绪释放。

### 写法重点

不要让主角太早爽。爽点之前要先让读者憋气。

例：
1. 未婚妻公开退婚。
2. 长老逼主角签字。
3. 族人嘲讽他没骨气。
4. 主角发现老祖生死矛盾。
5. 他没有立刻爆，而是先确认牌位、族谱、婚书日期。
6. 等长老说“老祖在此，岂容你放肆”，主角再问：“他三年前不是死了吗？”

这时爽点更足。

## 3. 主角情绪表达

主角不应该总是“邪魅一笑”。他可以有真实人的反应。

### 懵

适合穿越初期、校验结果超出预期。

表达：
- 他第一反应不是狂喜，而是把刚才那句话在脑子里回放了三遍。
- 他看着正在掉马甲的老祖，心里只剩一个念头：我刚才是不是嘴欠了？

### 怂

怂不是丢脸，是增加真实感。

表达：
- 林澈默默往柱子后退了半步，确认自己离门口更近一点。
- 他脑子里已经写好了遗言，标题叫《论校对如何把自己校死》。

### 冷静

冷静要通过“做事”表现。

表达：
- 他没有反驳，只把婚书翻到落款处。
- 他先看人，再看牌位，最后看向族谱上那个被香灰盖住的名字。

### 愤怒

主角愤怒最好不是吼，而是语言变短。

表达：
- “谁改的？”
- “把她的死，也写成必要剧情？”
- “那我今天偏要删了这个必要。”

### 愧疚

当主角修正剧情导致副作用，要写愧疚。

表达：
- 他看着被剧情补位的人，第一次没有吐槽。
- 系统提示音响了三遍，他都没有抬头。

## 4. 配角情绪表达

### 未婚妻/女主：从高傲到动摇

不要把她写成纯脸谱。她退婚可以有现实原因：家族压力、误解、保护主角、被剧情灌输错误记忆。

情绪层次：
1. 高冷：她认为自己在做正确选择。
2. 不耐：主角沉默让她失望。
3. 疑惑：主角指出第一个漏洞。
4. 惊慌：真相和她认知冲突。
5. 羞愧或防御：她不愿承认自己被剧情利用。

动作：
- 指尖捏紧婚书。
- 目光避开主角。
- 想说“你胡说”，但声音轻了。
- 在众人注视下挺直背，却比刚才更像强撑。

### 长老：权威破防

情绪层次：
- 压迫。
- 不屑。
- 被打断的不悦。
- 发现不对的迟疑。
- 强行维持体面。
- 彻底破防。

动作：
- 拍桌。
- 捻须。
- 茶盖敲杯沿。
- 眼神扫向其他长老寻求支持。
- 发现没人接话。

### 反派：不是蠢，是被逻辑追上

情绪层次：
- 掌控局面。
- 嘲笑主角找死。
- 发现主角说中一处细节。
- 试图转移话题。
- 发现世界开始校验。
- 从愤怒变成恐惧。

动作：
- 笑意卡在嘴角。
- 手指无意识摸向隐藏法器。
- 说话速度变快。
- 开始使用“你没有证据”这类防御性语言。

### 群众：放大器

群众是爽点扩音器，但不要只写“众人震惊”。

可写：
- 有人刚嗑开的瓜子掉进袖子里。
- 外门弟子低头看赌票，发现盘口当场变了。
- 刚才跟着嘲讽的人默默后退，假装自己只是路过。
- 族老们互相看，谁都不想第一个承认老祖可能是假的。

## 5. 情绪与搞笑的混合

搞笑不要破坏关键情绪。规则：
- 悲伤场景中，笑点只能来自主角克制的吐槽，不能嘲笑受害者。
- 高燃场景中，笑点放在爆发前或爆发后，不要打断核心燃点。
- 打脸场景中，笑点可以来自反派破防和群众反应。

例：
高燃前：
“林澈抬头看天劫，确认这玩意儿没有客服入口。”

高燃中：
“他收起所有乱七八糟的念头，只说了三个字：校验她。”

高燃后：
“雷云沉默了很久，像一个被甲方当场抓包的外包团队。”

## 6. 常见情绪写法模板

### 憋屈

环境压低声音，敌人占据高处，主角被迫站在众人视线中心。

句式：
- 大厅里很静，静到每一声嗤笑都像被放大。
- 林澈没有说话，因为他知道自己现在说什么都像狡辩。

### 反击前的冷静

句式：
- 他把那句话咽回去，重新看向婚书。
- 越是离谱，越不能急。急了就像嘴硬，慢一点，才像证据。

### 反转时的震惊

句式：
- 没有人说话。
- 不是不想说，是所有人都在等别人先承认自己看见了。
- 主位上的“老祖”脸皮正在脱落，像一张被水泡开的旧纸。

### 爽点释放

句式：
- 刚才压在林澈身上的目光，开始一寸寸移向主位。
- 那些嘲讽没有消失，只是换了方向。
- 沈清寒手里的退婚书忽然变得烫手。

### 章末不安

句式：
- 林澈还没来得及松口气，眼前又浮出一行字。
- 【修正成功。】
- 【但原剧情缺失的死亡名额，正在重新分配。】

## 7. 情绪自检

写完一段后检查：
- 是否出现太多“震惊、愤怒、尴尬、害怕”这类直白词？
- 读者能不能从动作看出情绪？
- 情绪有没有变化，而不是一整场都同一种状态？
- 搞笑是否服务情绪，而不是稀释情绪？
- 主角是否既有聪明，也有人的脆弱？
