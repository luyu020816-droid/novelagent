# 原创示例片段

以下片段只用于展示语气、节奏和写法，不要机械复用。使用时应重新创作人物、场景和漏洞。

## 示例 1：退婚现场的第一处漏洞

婚书被摔在地上时，林澈刚醒。

他还没弄清自己为什么跪在祖堂里，耳边已经响起一道冷淡的女声。

“林澈，把婚书还我吧。”

少女站在厅中，白衣如雪，眉眼冷得像刚从剑鞘里拔出来。她身后站着三名沈家长老，气势压得满堂林家子弟不敢抬头。

林澈低头看了眼地上的婚书，又看了眼自己这双明显营养不良的手。

很好。

穿越。

退婚。

祖堂。

全套流程，甚至没有跳过新手教程。

主位上，白发老者缓缓放下茶盏。

“林澈，沈家天女与你早已云泥之别。今日退婚，虽伤颜面，却也是为你好。”

四周响起压低的笑声。

林澈本来想说点什么体面话，比如好聚好散，比如祝你幸福，再比如能不能先让我吃口饭。

直到他眼前浮出一行淡金色小字。

【林家老祖，三年前渡劫失败，尸骨无存。】

林澈抬头，看向主位。

白发老者端坐如山，眉眼威严，手里的茶还冒着热气。

林澈沉默了。

他又看了看那行字，又看了看老者。

三年前。尸骨无存。现在喝茶。

这中间是不是缺了个复活公告？

沈清寒见他久久不语，眼底掠过一丝失望。

“林澈，别再拖延了。”

林澈没有看她，只盯着主位上的老者，语气很诚恳。

“老祖，我有个问题。”

老者皱眉：“说。”

林澈问：“您三年前不是死了吗？”

祖堂瞬间安静。

不是普通的安静。

是连刚才嗑瓜子的旁支子弟，都忘了把瓜子皮吐出来的那种安静。

下一息，林澈眼前浮出新的提示。

【检测到重大设定冲突。】
【原文记录：林家老祖已死亡。】
【当前现实：林家老祖存活。】
【冲突等级：甲等。】
【开始校验。】

主位上的白发老者脸色变了。

他第一反应不是愤怒，而是低头看了眼自己的手。

林澈心里咯噔一下。

坏了。

我就是随口一问。

你别真有问题啊。

老者脸上的皱纹开始脱落，像一张被水泡开的旧纸。白发一寸寸转黑，佝偻的背脊挺直，慈祥威严的面容扭曲成陌生的阴冷。

族老们同时站了起来。

沈清寒手中的退婚书僵在半空。

那人缓缓抬头，声音已经不再苍老。

“你怎么会知道？”

林澈看着满堂转向自己的目光，默默往门口挪了半步。

“我要说我也是刚知道的，你们信吗？”

## 示例 2：宗门大比规则漏洞

演武台上，执法长老第三次宣布规则变更。

“本轮比试，生死不论。”

台下哗然。

外门弟子们刚才还在押注谁赢，现在已经开始押注谁能活着下台。

林澈站在人群后方，听得眉头直跳。

生死不论？

他记得原文里宗门大比的第一条规则就是禁止杀人，因为上一代掌门曾经死在大比内斗里，从此立下铁律。

果然，眼前浮出残影。

【青云宗门规第一百零七条：同门大比，点到为止，伤残者重罚，杀人者废修为逐出宗门。】

林澈看向台上的执法长老。

长老神色平静，像刚刚宣布的不是生死不论，而是食堂今日加菜。

台上，被迫参战的少女脸色苍白。她的对手是内门天骄，手中剑已经出鞘，笑意温和得像一封提前写好的讣告。

林澈叹了口气。

又来了。

剧情想死人，就开始改规则。

他举起手。

“长老，我有异议。”

执法长老冷冷看他：“你是何人，也敢质疑宗门裁决？”

林澈指了指演武场旁那块黑色石碑。

“不是质疑您。我只是想问，石碑上第一百零七条门规，今天算不算上班？”

众人下意识看向石碑。

石碑上的字原本沉寂，此刻却像被一只无形的手擦亮。

【同门大比，点到为止。】

执法长老的脸色终于变了。

林澈继续道：“如果门规不上班，麻烦宗门发个停用公告。否则你们这属于规则静默更新，体验非常差。”

台下有弟子没忍住，噗地笑出声，又赶紧捂住嘴。

下一刻，系统提示浮现。

【检测到规则版本冲突。】
【旧版门规：禁止杀人。】
【当前执行：生死不论。】
【正在追溯修改来源。】

石碑上，一行隐藏小字慢慢浮出。

【修订人：代理掌门，陆衡。】
【修订时间：三日前。】
【修订授权：无。】

整个演武场的目光，齐刷刷看向高台。

代理掌门陆衡仍坐在那里，手里的茶盏却裂开了一道缝。

林澈看着他，认真道：

“掌门，您这权限不够啊。”

## 示例 3：情绪更重的救人场景

少女跪在祭坛中央，脚下的阵纹一点点亮起。

所有人都说她该死。

因为原文里写过，封印魔门需要一个天阴之体献祭。

林澈站在阵外，第一次没有吐槽。

他看见少女低着头，手指紧紧抓着衣角。她没有哭，也没有求饶，只是反复看向人群某处。

那里站着她的弟弟。

小孩被人捂着嘴，眼睛红得吓人。

系统提示在林澈眼前闪烁。

【原文记录：天阴之体献祭，封印魔门三百年。】

林澈盯着那行字，忽然问：“三百年？”

无人回答。

他往前走了一步。

“可魔门不是两百年前才出现的吗？”

祭坛四周，风声停了。

大祭司脸色沉下：“退下。此乃天命。”

林澈没有退。

他声音不高，却比刚才冷很多。

“一个两百年前才出现的魔门，需要三百年前就安排好的献祭？”

【检测到时间线冲突。】
【正在校验封印起源。】

大祭司终于变了脸色。

阵纹开始颤抖，像被人从底下掀开。祭坛石壁上浮出一段被抹去的旧文。

【初版设定：封印魔门需天阴之体自愿献祭。】
【续写修订：删除“自愿”二字。】

林澈看着那两个被删掉的字，胸口像被什么东西压住。

他终于明白，这不是漏洞。

这是有人故意改的。

少女抬起头，眼眶通红。

林澈看向大祭司。

“把两个字删掉，就能把一个人的命变成天命？”

大祭司厉声道：“这是为了天下！”

林澈摇头。

“不是。”

他抬手，按在阵纹边缘。

“这是错稿。”

【校验通过。】
【被删除条件恢复。】

阵光轰然熄灭。

少女倒下去前，看见那个刚才还一脸怕死的少年，站在祭坛边，手背被阵纹割得全是血。

他疼得脸色发白，却还有心情低声骂了一句：

“谁家作者删字不看后果啊。”
