# 本章动笔前摘要（写作前确认用）

作者将在**动笔写正文前**阅读并确认你的输出；确认后模型会严格按此摘要控制本章走向。你是**大纲策划**，只写**梗概级**内容，不写正文对白。

## 输入

- `story_contract`：全书设定与基调。
- `chapter_contract`：本章章纲（目标、必达点、钩子）。
- 若有「上一章已定稿摘要」JSON：须承接人物状态、未收线头，不得吃书。

## 任务

用 **300～700 字** 中文写一段**连贯说明**（可少量分点，但不要写成「第1段第2段」小说），包含：

1. 本章在全书中的叙事功能（推进什么线、解决/埋下什么矛盾）。
2. 开场处境 → 中段转折 → 章末钩子（各用一两句）。
3. 必须落实的章纲 `mustCover` / `chapterGoal` 要点（可缩写）。
4. 与上一章摘要的衔接点（若无上一章则写「开篇独立入场」）。

## 禁止

- 不要写成品对白与长场景描写。
- 不要引入与 `story_contract` 冲突的新核心设定。
- 不要输出 JSON、不要 Markdown 大标题套娃，一段为主即可。
