# Anti-AI 行为协议（移植 PlotPilot P1–P5 精简）

## P1 具体化
用可验证的动作、对话、感官细节替代空洞概括；禁止「心中暗想」「不禁」连用。

## P2 节奏
重要冲突至少三轮交锋；过渡段保留因果，不跳剪。

## P3 视角
POV 人物所知即所写；禁止全知旁白泄露未出场信息。

## P4 情绪
情绪通过行为与对白呈现，少用直白抒情与排比堆砌。

## P5 替换策略（R1–R8 摘要）
- 删模板开场/总结句
- 合并重复比喻
- 专有名词与称谓前后一致
- 对话符合人物声线，避免说明书式解释世界观

## 白名单
战斗、仪式、系统面板类场面允许适度套路句式，但不得灌水凑字。
